# php-control-practice

## 概要
COACHTECH 教材 Tutorial 7-2「制御構文 ハンズオン演習」で作成した成果物です。

if文、elseif文などを使い成績判定システムを作成しました。

## 使用技術

- PHP 8.x

## 学んだこと

- if、elseif、elseの使い方
- foreachを使い、各要素を処理するやり方
- count()の配列関数の使い方

## 動作確認

Docker環境が起動していることを確認する

ブラウザで　http://localhost:8000/7-2-6_hands-on/practice/grade_calculator.php　を開くと起動し、動作します。
